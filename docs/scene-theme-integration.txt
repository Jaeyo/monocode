MonoCode ← Scene 테마 연동 안내
================================

Scene(/Users/user/workspace-personal/Scene)에 MonoCode 연동을 붙일 때 지켜야 할
약속입니다. MonoCode 쪽 구현은 끝나 있습니다.
  - src-tauri/src/external_theme.rs          파일 찾기·읽기·변경 감시
  - src/features/settings/model/externalTheme.ts  형식 검증, 색 대응
Scene 쪽은 ZapFast·Zed 연동과 같은 방식(테마 파일 쓰기 + 설정 키 하나 바꾸기)이면 됩니다.


1. 앱 감지
----------
- 번들 ID: com.monocode.desktop
- 데이터 폴더: ~/Library/Application Support/com.monocode.desktop/
  (Tauri app_data_dir. XDG_CONFIG_HOME 등 환경 변수는 보지 않습니다.)


2. Scene이 쓸 파일 두 개
------------------------
(1) 테마 파일
    ~/Library/Application Support/com.monocode.desktop/themes/scene.json
    - themes/ 폴더가 없으면 만들어서 씁니다.
    - 파일 이름 규칙: 영문·숫자·'-'·'_'·'.'만, '.json'으로 끝남, '.'으로 시작 안 함,
      128자 이하. 경로 구분자('/')나 '..'은 거부됩니다.
    - 512KB를 넘으면 읽지 않습니다.
    - 권장: Operation.writeManagedFile

(2) 선택 키
    ~/Library/Application Support/com.monocode.desktop/appearance.json
    { "colorTheme": "scene.json" }
    - JSON 객체여야 합니다. 주석(JSONC)은 허용합니다.
    - 다른 키는 MonoCode가 건드리지 않고 보존합니다.
    - 권장: Operation.setJSONValue(path:, key: "colorTheme", value: .string("scene.json"))
    - 키가 없거나, null이거나, "" 이면 MonoCode는 기본 테마를 씁니다.
      → Scene의 Restore가 키를 원래 상태(없음)로 되돌리면 자동으로 기본 테마로 복귀합니다.
    - colorTheme가 가리키는 파일이 아직 없으면 오류 없이 기본 테마를 씁니다.
      그래서 쓰는 순서는 상관없지만, 테마 파일 → 선택 키 순서를 권장합니다.


3. 테마 파일 형식
-----------------
Scene의 ThemeFileRenderer.file(variants:appearance:mode:) 출력과 같습니다.
여기에 모드마다 "syntax"를 더할 수 있습니다(선택).

{
  "format": 1,                                   // 필수, 1만 지원
  "theme": { "id": "scene/tokyo-night",          // 선택
             "name": "Tokyo Night",              // 설정 화면에 표시. 없으면 파일 이름
             "version": "1.0.0" },               // 선택(쓰지 않음)
  "mode": "system",                              // "system" | "light" | "dark". 그 외 값은 system
  "appearance": "dark",                          // 있어도 됨(MonoCode는 쓰지 않음)
  "variants": {                                  // dark, light 중 하나 이상 필수
    "dark": {
      "interface": {                             // 15개 모두 필수
        "background", "surface", "overlay", "border", "foreground", "muted",
        "accent", "selection", "cursor", "currentLine", "search", "error",
        "warning", "success", "info"
      },
      "terminal": {                              // 6개 + ansi 모두 필수
        "background", "foreground", "cursor", "cursorText",
        "selectionBackground", "selectionForeground",
        "ansi": [16개 색, 0=black … 7=white, 8=brightBlack … 15=brightWhite]
      },
      "syntax": {                                // 선택. 일부만 있어도 됨
        "comment", "keyword", "operator", "punctuation", "string", "escape",
        "number", "constant", "function", "type", "builtin", "variable",
        "parameter", "property", "tag", "attribute", "added", "removed", "changed"
      }
    },
    "light": { ...같은 구조... }
  }
}

색 값 규칙
  - "#rrggbb" 또는 "#rrggbbaa"만 허용(대소문자 무관). 이름("blue")이나 "#rgb"는 거부.
  - syntax 값은 "#bb9af7" 문자열 또는 Scene 테마 형식의 { "color": "#565f89", "italic": true }.
    italic/bold는 현재 쓰지 않고 color만 씁니다.
  - syntax가 없는 키는 ANSI 색에서 채웁니다(keyword=magenta, string=green, function=blue,
    type/number=yellow, property=cyan, comment=muted 등). ThemeFileRenderer 출력만 그대로
    써도 동작하지만, 테마의 syntax를 넣어 주는 게 훨씬 정확합니다.

검증 실패 시
  - 필수 값이 하나라도 틀리면 그 파일 전체를 쓰지 않고 기본 테마를 씁니다.
  - MonoCode 설정(Appearance → Theme → External theme)에 이유가 표시됩니다.
    예: "scene.json: variants.dark.interface.accent is not a #rrggbb or #rrggbbaa color"


4. 모드(라이트/다크) 규칙
--------------------------
- 외부 테마가 선택된 동안에는 MonoCode 자신의 Theme 설정(System/Dark/Light)보다
  파일의 "mode"가 우선합니다.
    mode "system" → macOS 외관을 따라 dark/light를 고르고, macOS가 바뀌면 바로 따라갑니다.
    mode "dark"/"light" → 그 모드 고정.
- 고른 모드의 variant가 없으면 있는 쪽을 씁니다(한 모드만 있는 테마는 항상 그 모드).
- 따라서 Scene은 두 모드를 모두 넣는 것이 좋습니다(nativeVariants처럼). 그러면 macOS
  Light/Dark 전환 때 Scene이 다시 apply하지 않아도 MonoCode가 스스로 전환합니다.


5. 다시 불러오기(reload)
-------------------------
- 필요 없습니다. MonoCode가 1초마다 appearance.json과 themes/ 폴더의 파일 크기·수정
  시각을 확인하고, 바뀌면 열린 모든 창에 즉시 반영합니다.
- MonoCode가 꺼져 있으면 다음 실행 때 적용됩니다.
- reload는 .reloaded 또는 실행 중이 아니면 .notRunning을 돌려주면 됩니다.
  재시작 안내는 필요 없습니다.


6. MonoCode가 색을 쓰는 곳
---------------------------
interface.background   → 앱 배경, macOS 창 유리 색조, 터미널 OSC 11 응답
interface.foreground   → 기본 글자색(경계선·선택 영역은 이 색을 반투명으로 섞어 만듦)
interface.accent       → 강조색, 코드 블록 링크
interface.info         → 링크, @멘션
interface.warning      → skill 표시
interface.success/error→ diff 추가/삭제 색(접근성 diff 팔레트를 고르면 그쪽이 우선)
interface.error        → 오류 상자
interface.search       → 대화 검색 강조
terminal.*             → 내장 터미널(xterm) 글자·커서·선택·ANSI 16색.
                         터미널 배경은 창 유리 효과 때문에 투명으로 둡니다.
syntax.keyword         → 구문 keyword, 마크다운 제목 색
syntax.*               → 파일 에디터, diff, 채팅 코드 블록 구문 색
                         (에디터: keyword, function, string, type, number, comment,
                          property, attribute(meta) 사용 / 코드 블록: keyword, string,
                          escape, comment, constant, function, parameter, punctuation,
                          added, removed, changed 사용)
surface, overlay, border, selection, cursor, currentLine
                       → 형식상 필수지만 현재 쓰지 않음


7. 사용자가 MonoCode에서 되돌릴 때
-----------------------------------
- 설정의 "Use built-in theme"은 appearance.json에서 colorTheme 키만 지웁니다
  (다른 키 보존, 주석은 사라질 수 있음). 테마 파일은 남겨 둡니다.
- Scene 입장에서는 "사용자가 바꾼 값"이므로, 3-way 복원 규칙상 그대로 두면 되고
  changesOutsideScene에 잡히는 게 정상입니다.
- 사용자가 직접 정한 Accent color가 있으면 그 색이 테마 accent보다 우선합니다
  (메시지 말풍선, 보내기 버튼에만 쓰이는 개인 설정).


8. Scene 쪽 구현 제안
----------------------
- SceneRenderers/MonocodeRenderer.swift
    ThemeFileRenderer.file(...)과 같은 구조에 variant마다 "syntax"를 더해 출력.
    (ThemeFileRenderer를 재사용하고 syntax만 합치면 가장 간단합니다.)
- SceneIntegrations/MonocodeIntegration.swift  (ZapFastIntegration과 거의 같음)
    id "monocode", displayName "MonoCode", kind .editor
    detect: env.locateApp("com.monocode.desktop") 없으면 .notInstalled.
            appearance.json이 읽기 전용이거나 JSON 객체가 아니면 .blocked.
    plan:   [ .writeManagedFile(themes/scene.json, MonocodeRenderer 출력),
              .setJSONValue(appearance.json, "colorTheme", .string("scene.json")) ]
    reload: 프로세스가 있으면 .reloaded, 없으면 .notRunning (파일 감시로 자동 반영)
    verify: colorTheme 값이 "scene.json"인지 + Self.verifyFiles(plan)
- AllIntegrations.swift에 등록, docs/ARCHITECTURE.md의 Integrations 표에 한 줄 추가.


9. 직접 확인하는 방법
---------------------
1) themes/scene.json에 위 형식의 파일을 쓴다.
2) appearance.json에 {"colorTheme": "scene.json"} 을 쓴다.
3) 1초 안에 MonoCode 색이 바뀌고, 설정 → Appearance 맨 위에
   "External theme — Tokyo Night (scene.json)"이 보이면 성공.
4) appearance.json에서 colorTheme을 지우면 1초 안에 기본 테마로 돌아온다.
